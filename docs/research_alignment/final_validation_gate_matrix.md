## 1. Executive Summary and Classification Standard

This document presents the complete validation audit matrix for all 22 quantitative evaluation metrics and software invariants in SYNAPSE Phase 2. Every metric verdict is governed by a rigorous six-tier taxonomy:

- **`PASS`:** A predefined, scientifically justified acceptance criterion has been met against an identifiable empirical benchmark.
- **`SOFTWARE_INVARIANT_PASS`:** A deterministic, non-negotiable software invariant has been verified with zero violations.
- **`WARNING`:** The metric is usable for research but carries an identified, material caveat (e.g., small-sample age stochasticity).
- **`UNVERIFIED`:** Empirical evidence or reference alignment is insufficient to substantiate real-world fidelity.
- **`NOT_COMPARABLE`:** Synthetic and real-world reference quantities measure incompatible estimands.
- **`FAIL`:** Predefined acceptance criteria or invariants were violated.
